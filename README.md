# Python with Django – 3rd Assessment

This repository contains two projects developed as part of the **Python with Django Training – 3rd Assessment at Webskitters**.

## Projects

- **Question 1 – Attendance Audit System:** A Python-based application for processing CSV attendance records, validating timestamps, and handling exceptions.
- **Question 2 – Support Ticket System:** A Django-based web application for submitting support tickets, uploading screenshots, and suggesting ticket priorities automatically.

## Technologies Used

- Python
- Django
- HTML & CSS
- CSV & JSON
- Regular Expressions
- Exception Handling
